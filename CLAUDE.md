## Project

- AIを使った学習Webアプリ。ユーザーが好きなテーマを学べる。
- 今後導入する技術：shadcn/ui / Zod / Supabase（認証・DB）/ Stripe（サブスク課金）/ Anthropic API / Vercel（デプロイ）
- 秘密キー（`SUPABASE_SECRET_KEY`, `STRIPE_SECRET_KEY`, `ANTHROPIC_API_KEY`）はサーバー側でのみ使い、`NEXT_PUBLIC_` を付けない。`.env.local` に置き、コミットしない（`.gitignore` の `.env*` で除外済み。`.env.example` のみコミット可）。
- DBの変更は必ず Supabase migration で行い、テーブル作成時に RLS を有効にする。
- 開発環境は Windows + PowerShell 7。改行コードは LF（`.gitattributes` で固定）。
- ユーザーとのやり取りは日本語で行う。

## Commands

npm is the package manager (`package-lock.json`). Node 24.21.0 is pinned via Volta.

- `npm run dev`: dev server at http://localhost:3000
- `npm run build`: production build (also runs type checking)
- `npm run start`: serve the production build
- `npm run lint`: ESLint 9 flat config (`eslint.config.mjs`, extends `eslint-config-next` core-web-vitals + typescript)
- `npx tsc --noEmit`: type-check on its own

No test framework is set up yet.

## Stack and structure

- Next.js 16 App Router with React 19 and TypeScript (strict). The source lives under `src/app/`, not a root `app/` (the README is out of date on this).
- `@/*` resolves to `./src/*`.
- Tailwind CSS v4, configured CSS-first: there is no `tailwind.config.*`. Theme tokens are declared in `src/app/globals.css` with `@theme inline`, which maps the CSS variables `--background`/`--foreground` and the Geist font variables (loaded with `next/font` in `layout.tsx`) to Tailwind utilities. Dark mode follows `prefers-color-scheme`.
- Route prop types such as `LayoutProps<"/">` / `PageProps<...>` are global helpers generated by Next into `.next/types` (that's why tsconfig includes them). Use them instead of hand-writing props types. They exist only after `next dev`/`next build` (or `next typegen`) has run.
