## アプリの特徴
知っていることは、もう解かなくていい。
あなたの「わかる」を覚えている学習アプリ、Nile-Sea

資格の勉強を始めたら、別の教材でもう覚えた単語がまた出てきた。そんな経験はありませんか。
Nileは、問題集が違っても、あなたがすでに身につけた問題や知識を見分けて、自動で省きます。解くのは、まだ身についていない問題だけ。限られた時間を、本当に必要な学習に使えます。

■ 重複を省く範囲は、あなたが決める
・問題集ごとに独立：一冊ずつ、基礎から確実に固めたい人に
・同じ問題を省く：一度解けた問題は、どの問題集でもスキップ
・同じ知識を省く：問題文が違っても、同じ単語や概念を問う問題はまとめてスキップ

■ 「覚えた」の基準も、あなたが決める
1回正解でクリアにするか、2回連続で正解するまで出題し続けるか。設定を変えると、これまでの学習結果もその場で判定し直します。

■ 間違えた問題だけを、すぐに復習
不正解だった問題を自動で集めて、復習モードで出題します。別の問題集で間違えた知識も、ちゃんと復習の対象に入ります。

■ 毎日の積み重ねが見える
今日の回答数、正答率、学習時間、連続学習日数。カレンダーで、がんばった日がひと目で分かります。

■ まもなく登場
・考え方の型の分析：「抽象→具体」「原因→結果」など、問題ごとの思考パターンから、分野をこえたあなたの苦手を見つけます
・習得済み率の表示：新しい問題集を始める前に「すでに60%習得済み」が分かります
